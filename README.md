# 欢云 HUANCLOUD - 云服务VPSM 面板首页主题

> 智在云端，欢享无限！

基于 Material Design 3 设计规范构建的现代化云服务网站首页主题，为 VPSM 面板量身定制。

## ✨ 特性

- 🎨 **Material Design 3 设计语言** - 遵循 Google MD3 设计规范，提供一致且现代化的用户体验
- 📱 **完全响应式设计** - 完美适配桌面端、平板和移动设备
- 🎭 **滚动动画** - 使用 Intersection Observer API 实现流畅的入场动画效果
- 🔝 **智能导航** - 自动高亮当前视口对应的导航链接
- 📲 **移动端抽屉导航** - 优雅的侧边抽屉导航，支持手势操作
- ⚡ **高性能** - 纯 HTML/CSS/JavaScript 实现，无外部框架依赖
- 🌐 **中文字体优化** - 使用 Noto Sans SC 字体，确保中文显示效果
